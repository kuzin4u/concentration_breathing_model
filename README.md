# Концентрация и дыхание — интерактивная модель

Интерактивная визуализация авторской системы **«Концентрация и дыхание для здоровья, когнитивных способностей и интуиции»**.

## Как использовать

1. Скачайте файл `concentration_breathing_model.html`
2. Откройте в любом современном браузере (Chrome, Firefox, Safari, Edge)
3. Нажмите **«Запустить — активировать звук»**

Файл полностью автономен — интернет не нужен.

## Возможности модели

### 🫁 Дыхание
- 4 управляемые фазы: **вдох · задержка↑ · выдох · задержка↓**
- Время каждой фазы задаётся отдельно (сек)
- Синхронизация каждой фазы с концентрацией (0–100%)
- Реальный звук мужского дыхания
- Кровеносная система тела наполняется цветом по фазе: зелёный (вдох) / красный (выдох)

### 🎯 Концентрация — импульс от мозга
- Частота импульсов (уд/мин)
- Сила импульса (1–5)
- **15 органов-целей** с анатомическими контурами на теле:
  - Глаза, Мозг, Лёгкие, Сердце, Желудок, Солн. сплетение
  - Поджелудочная, Печень, Селезёнка, Почки
  - Тонкий кишечник, Толстый кишечник, Прямая кишка
  - Мочевой пузырь, Половые органы
- **Режим мыши** — точку прихода импульса можно указать кликом
- При синхронизации >50% — сила импульса ×1.5

### ♥ Сердечный пульс
- Частота 40–120 уд/мин
- Реалистичный звук «луб-дуб»
- Независимая громкость

### ⏱ Управление скоростью
- От 0.2× (замедленно) до 2× (ускоренно)
- Для детального изучения процессов

## Теоретическая основа

Модель реализует авторскую концепцию:
- **Концентрация** — универсальный инструмент, вектор которого определяется доменом применения
- **Три домена**: Здоровье · Когнитивные способности · Интуиция
- **Механизм**: дыхание и концентрация — две спирали, воздействующие на ось-тело через нейронную сеть
- **Синхронизация** спиралей создаёт резонанс и усиливает воздействие
